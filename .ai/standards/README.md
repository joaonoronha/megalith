# Global Engineering Standards

This directory establishes lightweight, ecosystem-agnostic engineering standards for the Megalith monorepo. These standards ensure consistency and safety across all products and AI coding interactions.

## Standards Index

| Standard | Description |
|:---|:---|
| [Naming Conventions](naming-conventions.md) | Repositories, products, services, directories, branches, and commit formats |
| [Boundaries and Dependencies](boundaries-and-dependencies.md) | Product isolation, service independence, shared packages, and dependency hygiene |
| [Code Quality and Testing](code-quality-and-testing.md) | Simplicity, error handling, linting, and automated test expectations |
| [Configuration and Secrets](configuration-and-secrets.md) | 12-factor configuration, environment files, and zero-leakage secrets rules |
| [Documentation and ADRs](documentation-and-adrs.md) | Documentation hierarchy, ADR lifecycle, format, and documentation maintenance |
