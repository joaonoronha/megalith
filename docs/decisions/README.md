# Architecture Decision Records (ADRs)

This directory documents the core architectural decisions that govern the repository. Every significant architectural choice is documented as an ADR using the format:
- **Context**
- **Decision**
- **Rationale**
- **Alternatives Considered**
- **Consequences**
- **Status**
